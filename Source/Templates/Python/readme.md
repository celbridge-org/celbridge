# Welcome to Celbridge!

This project is a Python starter, containing 2 files for demonstrating Python development:

- `python.console`
- `hello_world.py`

## Step 1: Open the Python console

Open the Python console, either:
- double click file `python.console` document in the **Explorer** panel
- or click the Python console shortcut in the Utility bar on the left: <img src="https://cdn.jsdelivr.net/npm/bootstrap-icons@1.11.3/icons/terminal.svg" width="24" height="24" alt="terminal icon"> 

You should see the `python.console` document open in the bottom document panel in the Celbridge application
- if you can't see this console open, then display the bottom document using this layout button at the top right of the Celbridge application: <img src="https://cdn.jsdelivr.net/npm/lucide-static/icons/panel-bottom.svg" width="24" height="24" alt="bottom panel icon">


## Step 2: Run program `hello_world.py`

Either:
- type `run hello_world.py` in the Python Console
- or choose `Run` from the context (Right-Mouse-Button) menu for the `hello_world.py` document in the Explorer panel

You should then see the following output in the console:
```bash
>>> run "hello_world.py"
Hello, world!
```

## Next steps...

Now you can:
- edit `hello_world.py` to display another message
- create a new Python script and run it
- directly type commands into the Python terminal, e.g.

```bash
>>> print (2+2)
4
```
